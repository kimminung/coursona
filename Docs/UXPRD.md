# 코르소나 (Coursona) — UI/UX 디자인 PRD

> 작성일 2026-10-05 · 상태 v1.0. 근거: `Docs/TechPRD.md` v0.2, `Docs/UIUX-Prompt.md`(디자인 AI 요청문), `Docs/Stitch-Request.md`, 그리고 Google Stitch 산출물 20종(`Docs/stitch_new_project_starter/`, `Docs/stitch_new_project_starter 2/`).
> 이 문서는 Stitch 가 만든 화면을 그대로 베끼지 않는다. 테크PRD §13(UX 범위)·§14(미결 사항 기본값)를 기준으로 **맥락에 맞는 요소만 채택**하고, 테크PRD와 충돌하는 요소는 §1-2에서 명시적으로 배제한다.

## 0. 입력 자료 요약

Stitch 산출물은 두 디자인 토큰 세트로 왔다.

- **Liquid Stage**(`stitch_new_project_starter/.../liquid_stage/DESIGN.md`, 다크 기본) — 3D 뷰포트를 중심에 두는 어두운 스테이지(#0B0D12~#14171F) + 플로팅 글래스 필. Tier 배지 색(A=#007AFF·B=#32ADE6·C=#8E8E93), 성공/경고/오류(#34C759/#FF9F0A/#FF453A) 를 이미 정의해 놓았다. **이 문서의 기본 테마로 채택.**
- **Liquid Glass Light**(`stitch_new_project_starter 2/.../liquid_glass_light/DESIGN.md`) — 밝은 배경 변형. 라이트 모드 대안으로 채택, 뷰포트 받침은 다크 유지(`#0F172A`).

화면 20개 중 18개는 테크PRD와 맞고 즉시 재사용 가능한 수준이었다. 2개(아이패드 가로 2장)는 Stitch 자체의 **CSS 겹침 버그**로 레이아웃이 깨져 있어 내용만 참고하고 레이아웃은 재설계했다. Mac 화면 1개(`stitch_new_project_starter 2/mac`)는 테크PRD와 **충돌하는 하드웨어·용어**(LiDAR, Apple Neural V5, 광학 굴절 지수, DoF f/1.4)를 포함해 그 부분만 배제했다.

## 2. 되묻는 질문 (테크PRD 작성자에게)

1. Mac 인스펙터의 "환경 설정" 탭에 정확히 무엇을 넣을지(테크PRD에 조명 슬라이더·머리카락 틴트는 있으나 탭 구성은 미정) — 이 문서 §5-4에서 "조명 보정·머리카락 틴트·배경 분리 민감도" 세 항목으로 가정.
2. Stitch 가 제안한 "거리 48cm(최적)" 같은 카메라-얼굴 거리 안내가 테크PRD 캡처 게이트(각도만 정의)에 없는데 넣을지 — 이 문서는 **보조 안내로 채택**(각도 게이트를 대체하지 않음).
3. iPhone 하단 탭을 "스튜디오·갤러리·정밀도·기기 연동" 4개로 둘지, 아니면 §3 처럼 평면 흐름으로 둘지 — 두 Stitch 화면(`_4`,`_5`)이 독립적으로 같은 4탭을 제안해 **이 문서는 4탭을 채택**했다. 테크PRD §13 과 다른 점이므로 확인 필요.

답이 없으면 위 가정대로 진행한다.

## 3. 디자인 원칙

1. **뷰포트가 주인공.** 모든 화면에서 흉상이 가장 크고, 컨트롤은 그 위를 떠다니는 얇은 글래스 필(캡슐)로만 존재한다.
2. **숫자는 숨긴다, 결론은 보인다.** "겹침 없음 ✓" 은 항상 보이고, mm·RMS 같은 수치는 "자세히"를 눌러야 나온다.
3. **등급을 부끄러워하지 않는다.** B·C 등급은 "지금 바로"의 장점으로, A 등급은 "더 정밀하게"의 선택으로 말한다. 열등 표현 금지.
4. **세 플랫폼, 하나의 말투.** 아이폰·아이패드·맥이 같은 색·같은 문구·같은 배지를 쓴다. 차이는 입력 방식과 창 구조에서만 난다.
5. **조용한 신뢰.** 블러·그림자는 Liquid Glass 토큰값을 그대로 쓰고, 장식적 모션을 더하지 않는다.

## 4. 정보 구조·내비게이션

### iPhone / iPad(세로)
탭 바(하단, Liquid Glass) 4개 — Stitch `_4`·`_5` 에서 수렴한 구조를 채택:

- **스튜디오**(홈): 현재 활성 페르소나 미리보기 + 3-등급 "새로 만들기" 진입(비어 있으면 화면 1 전체가 뜬다).
- **갤러리**: 라이브러리(화면 7).
- **정밀도**: 활성 페르소나의 검수/품질 카드(화면 4)로 바로 진입.
- **기기 연동**: 보내기/받기 허브(화면 6b).

캡처·빌드·거울·저장은 탭이 아니라 **스튜디오에서 시작하는 전체화면 모달 흐름**(push 또는 풀스크린 시트)이다.

### iPad(가로, 캡처 중)
같은 4탭이지만 캡처 모달에서는 탭 바가 숨고, 캡처 칩 열이 **왼쪽 세로 칼럼**, 셔터/건너뛰기/팁이 **오른쪽 세로 칼럼**으로 분리되어 중앙 4:3 안전영역을 가리지 않는다(`stitch_new_project_starter 2/ipad_1`의 겹침 버그를 이 구조로 대체).

### Mac
상단 통합 툴바 4탭(`starter/_11`·`starter/mac` 그대로 채택): **스튜디오 · 공간 촬영 · 거울 모드 · 보관함**. 본문은 3단 — 왼쪽 사이드바(페르소나 목록, 240–280px) · 중앙 뷰포트(가변) · 우측 인스펙터(품질 진단/환경 설정 탭, 300px). 인스펙터는 창이 좁아지면 팝오버로 접힌다.

```

  → 빌드 → 검수("크기 추정" 배지 유지) → 거울(Mac: 2초 캘리브레이션) → 저장

```

## 6. 화면별 스펙

각 화면은 **목적 → 레이아웃(플랫폼별) → 상태 → 컴포넌트 → 문구 → 접근성** 순.

### 화면 1 — 시작·등급 안내
원형: `stitch_new_project_starter/_1/screen.png`.

- **목적**: 세 진입점을 동등하게 제시, 아무것도 막지 않는다.
- **레이아웃**: iPhone/iPad 세로 — 상단 아이콘 + 제목 + 한 줄 설명, 3개의 가로 카드(등급 배지·권장 리본·제목·부제·예상 시간), 하단 "이미 만든 코르소나 열기" 링크, 최하단 프라이버시 한 줄. iPad 가로는 3카드를 가로 3열로. Mac은 별도 화면 없이 사이드바의 "새 코르소나 생성" 3버튼 행(§6 Mac-1)으로 대체.
- **상태**: 기본 / 카메라 권한 미확인(카드 탭 시 화면 8로 라우팅) / 저장된 페르소나 없음(기본과 동일, 링크만 비활성).

## 9. 모션·햅틱·사운드

- 자동 촬영 순간: 링 100% 채움 + 가벼운 햅틱(success) + 셔터 사운드(시스템). 실패 시 링이 절반에서 비워지며 경고 햅틱 없음(과도한 피드백 방지).
- 빌드 단계 전환: 체크 아이콘이 0.2초 스케일 바운스.
- 품질 배지 초록→빨강 전환 시 색만 바뀌고 쉐이크 없음(차분한 어조 유지).
- 거울 캘리브레이션 완료: 링이 채워지며 부드러운 페이드로 메인 뷰 전환.
- 전송 완료: 진행 바가 100%에서 체크로 모프, 성공 햅틱 1회.
- 동작 줄이기(Reduce Motion) 설정 시: 모든 스케일/페이드를 즉시 전환으로 대체, 링 진행은 유지(정보 전달용이라 모션 감소 대상 아님).

## 10. 접근성 체크리스트

- Dynamic Type 접근성 큰 글자: 컷 칩 열 2행 래핑, 포즈 세그먼트는 2×3 그리드로 전환, 버튼 라벨 줄임 금지.
- VoiceOver 읽기 순서: 상태 배지 → 주요 콘텐츠(뷰포트/사진/목록) → 보조 토글 → 하단 액션. 각도 링은 "현재 15도 오른쪽, 허용 14도, 0.3초 유지 중"처럼 수치를 말로 변환.
- 색 비의존: 겹침 없음/경고/오류는 아이콘(체크/느낌표/엑스)과 텍스트를 항상 동반, 색만으로 구분하지 않음.
- 대비: 다크 테마 본문 텍스트 on-surface(#E2E2E9) 대 배경(#0B0D12~#14171F) 모두 7:1 이상. 글래스 필 위 텍스트는 불투명도 최소 92%(모달)로 올려 대비 확보.
- 모션 감소: §9 대응.
- 음성 안내(선택, 기본 꺼짐): 켜면 캡처 단계 안내를 소리로도 제공.

## 12. 수용 기준 (테크PRD §9 실기기 체크리스트와 연결)

- 화면 2(A): 실기기에서 7컷이 0.5초 유지로 자동 촬영되고, 칩이 실시간으로 완료 표시되면 완료.
- 화면 4(검수): A 등급 실기기 결과에서 "겹침 없음 ✓" 이 실제로 자기교차 0건일 때만 뜨는지 QA 확인.
- 화면 6(거울, Mac): 캘리브레이션 2초 후 입·눈썹·깜빡임이 카메라를 따라가면 완료, 지연 체감 없음(<120ms).
- 화면 7(전송): iPhone→Mac 6자리 코드 입력 후 52MB 전송이 완료되고 Mac 쪽이 같은 모습으로 열리면 완료.
- 화면 8(업그레이드): B→A 병합 후 이름·머리 스타일이 그대로이고 등급 배지만 바뀌면 완료.
- 전 화면: 기술 용어(RMS, RBF, ARKit, 스플랫, 자기교차라는 단어 자체도 "진단 상세"에서만)가 1차 화면에 노출되지 않으면 완료.
